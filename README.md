# Very Simple Tester for Web Sockets

## Install

* `git clone https://github.com/levanroinishvili/web-socket-tester.git`
* `cd web-socket-tester`
* `npm install`

## Run

* `node index.js`
* Select the port and press enter
* Connect from client (See [Connecting from Browser](#connecting-from-browser) for an example)
* Connection information and messages will appear in the console
* Type in console a message and press Enter to send to all connected WebSockets

## Connecting from Browser

To test sockets from the browser, open the included file [websocket.html](websocket.html) in the browser. Use buttons `Connect` and `Send to All`.
